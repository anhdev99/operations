GĐ1 · Nền tảng và kết nối

Biết mình có gì để đọc và đọc được thật, trước khi viết bất kỳ tự động hoá nào. Phần lớn việc ở đây cần bạn thao tác trên web để cấp token.

Việc trong giai đoạn

V1.1

Kiểm kê nguồn của từng nơi

Đang làm
Mục tiêu
Biết chính xác mỗi nơi có gì để đọc: project, kênh, repo, và bạn có quyền gì.
Tệp
  • Tạounits/<role>/sources.json (×3)
Phụ thuộc
Không
  1. Liệt kê OpenProject. Với mỗi nơi: URL, project bạn tham gia, vai trò. Với LucidTech chạy 
    set -a; . ~/.claude/lucidtech-openproject.env; set +a
curl -s -u "apikey:$OP_TOKEN" "$OP_BASE_URL/api/v3/projects"
  2. Liệt kê Kimai. URL, có bật API không, project/hoạt động nào bạn ghi giờ.
  3. Liệt kê GitHub. Org và repo của từng nơi; tài khoản dùng (cá nhân hay riêng cho công ty).
  4. Liệt kê Slack. Workspace, kênh bạn cần theo dõi, kênh thông báo CI.
  5. Hỏi chính sách. Mỗi công ty có cho phép đọc dữ liệu bằng công cụ ngoài không (Q3).
Kiểm chứng: ba tệp sources.json có đủ 4 mục, không có token; bảng giả định được cập nhật từ “chưa kiểm” sang đúng/sai.
V1.2

Dựng khung repo và ngữ cảnh từng nơi

Đang làm
Mục tiêu
Có sẵn cây thư mục và CLAUDE.md để mỗi lần làm việc ở nơi nào, Claude chỉ nạp ngữ cảnh nơi đó.
Tệp
  • TạoCLAUDE.md
  • Tạo.gitignore
  • Tạounits/*/CLAUDE.md
  • Tạoteaching/term-calendar.html
  • Tạoshared/week-calendar.html
Phụ thuộc
V1.1
  1. Viết CLAUDE.md gốc: ba luật: chỉ đọc mặc định, không trộn dữ liệu giữa các nơi, token ở ~/.claude.
  2. Viết CLAUDE.md từng nơi: vai trò của bạn, người liên quan, quy ước đặt tên ticket, giờ làm việc.
  3. Nhập khung giờ cố định vào shared/week-calendar.html (họp định kỳ, giờ lên lớp).
  4. Thêm .gitignore: units/*/snapshot/, *.env.
Kiểm chứng: git status không liệt kê snapshot hay env; mở từng CLAUDE.md thấy đúng ngữ cảnh của nơi đó.
V1.3

Kết nối chỉ đọc 4 hệ thống

Đang làm
Mục tiêu
Mỗi hệ thống gọi được bằng một lệnh, ra JSON, không ghi gì.
Tệp
  • Tạo~/.claude/<role>.env (ngoài repo)
  • Sửacấu hình MCP Slack, GitHub
Phụ thuộc
V1.1
  1. Nơi để điền: mỗi nơi một tệp env duy nhất ở ~/.claude/<role>.env (chmod 600), chứa OP_BASE_URL/OP_TOKEN, KIMAI_BASE_URL/KIMAI_TOKEN, SLACK_TOKEN. Tệp mẫu đã tạo sẵn, giá trị để trống.
  2. Kiểm tra: chạy python3 scripts/check_setup.py. Lệnh này cho biết nguồn nào đã điền và chạy được, không in token.
  3. OpenProject: My account → Access tokens → API. Kimai: Profile → API Access (đã viết kimai_read.py, chưa kiểm với Kimai thật). Slack: user token xoxp- có search:read; hoặc xác thực plugin Slack nếu không cài được app (Q3).
  4. GitHub: dùng gh, không cần token; MCP GitHub vẫn lỗi HTTP 400, bỏ qua.
Kiểm chứng: mỗi nơi có một lệnh đọc trả về dữ liệu thật (5 bản ghi); thử một lệnh ghi bị chặn bởi luật chỉ đọc trong CLAUDE.md.
