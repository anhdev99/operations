Ví dụ sources.json

Chỉ chứa tên và định danh, không chứa token. Token nằm ở ~/.claude/<role>.env.

{
  "name": "lucidtech",
  "env_file": "~/.claude/lucidtech.env",
  "openproject": { "projects": ["dthu-cees"] },
  "github": { "owners": ["lucidtechnology"] }
}

Mỗi nơi một tệp env chứa mọi token (OP_*, KIMAI_*, SLACK_TOKEN). Script đọc thẳng tệp này, không đưa token vào môi trường chung. Hệ thống nào còn trống thì script báo not_configured chứ không bỏ im.
